# maurosalud

Sistema de seguimiento y fidelización de tratamientos para el Centro Médico Vida Norte SpA.
Proyecto del equipo ARM Systems (Instituto Profesional Santo Tomás, Arica), asignatura Gestión de Proyectos y Equipos de Trabajo.

Para clonar, instalar, crear la base de datos, configurar las credenciales y levantar el sistema, sigue la [guía de puesta en marcha](GUIA_PUESTA_EN_MARCHA.md).

## Contenido del repositorio

| Carpeta | Qué contiene |
|---|---|
| `arm-seguimiento/` | El sistema: `backend/` (NestJS), `frontend/` (Angular), `docs/` (diagramas, código documentado y presentaciones) y `qa/` (batería de pruebas de la API) |
| `Evaluacion_3/` | Los cinco planes de gestión de la Evaluación N°3, con sus anexos en Excel, el cronograma de GanttProject y el zip de entrega |
| `Proyecto_SeguimientoTratamientos_ARMSystems/` | Documentos de gestión de la Evaluación N°2 |
