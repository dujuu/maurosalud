    Class ResumenDoctor

    Resumen calculado con las recomendaciones que el doctor realmente envió: no hay cifras de ejemplo. Responde dos preguntas: ¿se están leyendo mis indicaciones? y ¿quién tiene pendientes hace más tiempo?
